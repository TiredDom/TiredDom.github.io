Privacy policy

Last updated: October 27, 2026.

"rclone" (Google Cloud project "rclone") is a private tool used only by its owner, TiredDom, to upload the owner's own videos from the owner's computer to the owner's own Google Drive.

What it can access

It uses Google's drive.file permission, so it can see and change only the files and folders it creates in Google Drive. It cannot see any other file in the Drive.

What it collects and shares

Nothing. No data is sent to anyone else, sold, or used for advertising. The sign-in token stays on the owner's own computer.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at https://myaccount.google.com/permissions.
